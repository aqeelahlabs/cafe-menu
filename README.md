# Cafe Menu

A cafe menu web page for a fictional cafe called Camper Cafe, with a Coffee section and a Desserts section. Each item shows its name on the left and its price on the right. Built as part of the freeCodeCamp curriculum.

## Live Demo

https://aqeelahlabs.github.io/cafe-menu/

## Features

- A centered menu card that resizes with the browser window, using an `80%` width with a `max-width`
- Coffee and Desserts sections, each with an icon image
- Item names aligned to the left and prices aligned to the right
- A bean pattern background image and `Impact` headings
- Horizontal rules styled in brown to separate the sections
- A footer with an address and a link to freeCodeCamp that opens in a new tab
- Link colours that change on hover and when clicked

## What I Practised

- Styling elements with type, class and descendant selectors
- Grouping shared styles with selector lists
- Centering with `text-align` and `margin-left` / `margin-right: auto`
- Sizing with percentage widths and `max-width`
- Placing items side by side with `display: inline-block`
- Adding spacing with `margin` and `padding`
- Styling images, `hr` elements and the `background-image` property
- Styling link states with `:visited`, `:hover` and `:active`
- Structuring the page with `main`, `section`, `article`, `footer` and `address`

## Built With

- CSS3
